Zero-knowledge Succinct Non-Interactive Argument of Knowledge (zk-SNARK) circuit compiler and verifier in Rust.

## Architecture Overview
This system is architected for enterprise-grade throughput, strict fault tolerance, and minimal allocation overhead.

## Core Highlights
- Fully modular design with clean separation of concerns.
- Optimized for modern hardware acceleration and zero-copy data paths.
- Comprehensive telemetry, observability, and unit/integration test coverage.
